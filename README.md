A make.fun entry for [One Line, No Deadline Met](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce):
one single-line joke excusing a missed deadline, 200 characters or fewer.

The program (`main.ts`, Node 22) writes the line to
`${MAKEFUN_OUTPUT_DIR ?? "/output"}/entry.txt`. The line is one specific
scene: the speaker moved the deadline themselves at 2 a.m. while half
asleep, then spent the morning angry at whoever moved it.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/no-deadline-met-out node main.ts
cat /tmp/no-deadline-met-out/entry.txt
```
